🗂 資料清理

定期清除舊訂單以維持資料庫效能
清除後資料無法復原，建議先匯出全部歷史備份。
若要自動排程清除，請到 Supabase → SQL Editor 執行 pg_cron 設定（見下方 SQL）。
-- Supabase SQL Editor → 自動每月 1 日清除 6 個月前訂單
SELECT cron.schedule(
  'auto-delete-old-orders',
  '0 2 1 * *',
  $$DELETE FROM orders WHERE submitted_at < NOW() - INTERVAL '6 months'$$
);
-- 查看排程狀態：SELECT * FROM cron.job;
-- 取消排程：SELECT cron.unschedule('auto-delete-old-orders');
